# ExamAdda

ExamAdda is a simple, student-focused website for Indian government exams and government jobs.

## Core purpose

Bring exam and job information into one structured place: eligibility, qualification, age, application, dates, syllabus, pattern, selection process, posts/jobs and official source.

## Source principle

Official recruiting authority websites remain the authoritative source for applications, notifications, dates and rules. ExamAdda organizes information for students and should not invent missing details.
